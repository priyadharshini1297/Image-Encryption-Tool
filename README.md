 Image Encryption Tool
A Java-based application for encrypting and decrypting image files using a user-defined key.

 Features
1. Image encryption and decryption
2. Key-based security
3. Simple command-line interface
4. Java file handling

 Technologies
1. Java
2. File Handling
3. Encryption & Decryption

 Usage
1. Select Encrypt or Decrypt.
2. Enter the image file name.
3. Enter the output file name.
4. Enter the encryption key.

 Example
* Input: sample.jpg
* Encrypted: encrypted_image.enc
* Decrypted: decrypted.jpg
